Tech, explained

Start with the job you need to do, then understand the mechanism and its limits. These existing explainers use diagrams, films and clearly labeled examples.

By Ahmadreza Samadi

Choose an explanation for the decision

For a device problem, compare the parts of the connection before guessing at one cause. For an AI answer, inspect the supporting source before relying on fluent wording.

For a calculation, check the inputs and what the result leaves out. The films and illustrated examples make those checks visible; they do not report customer outcomes.

Start with the decision, then build the AI: Define one decision, the evidence it needs and a useful first experiment.

Three checks before acting

  • What job do I need the technology to do?
  • Which source, setting or input supports the answer?
  • What remains uncertain, and what should a person check?
