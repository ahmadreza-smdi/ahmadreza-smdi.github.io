The situation

Noor, a fictional business owner, receives a neatly organised extraction from a document. Every field fits the form. One value has no support in the source. A tidy shape and a true statement are different checks.

What the source supports

OpenAI documents Structured Outputs as a feature that makes model responses adhere to a supplied JSON Schema, using a supported subset of JSON Schema. It also states that outputs can still contain mistakes and that refusals or incomplete responses need handling. Support and schema constraints vary. [OASTRUCT]

Practical questions

Our original three gates are format → source → business rule. First check that the response completed in the expected form. Then match each important value to the actual document. Finally check the business requirement separately. Make room for unknown or missing data instead of forcing a guess into a required answer.

Limits and disclosure

Noor pauses the unsupported value for review. This fictional resolution illustrates a control; it is not a tested application or a claim that schema enforcement certifies facts.
