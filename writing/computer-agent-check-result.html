How the loop works

Anthropic describes a computer-use loop: the model requests an action, the application executes it, and observations return to the model. Its documentation warns that the model may assume an outcome without checking. This screenshot-based design does not describe every web agent. Anthropic: Computer use tool (opened 28 October 2026)

Observe, act, verify

Our original check is observe → act → verify. Observe the current state, not an old picture. Act on a clear target. Verify the actual draft and visible status afterwards. A tool saying it ran a click is different evidence from a completed label.

When the result is unclear

When the result is unclear, inspect the current state and replan rather than blindly repeating a potentially consequential action. Separate approval for consequential actions is our recommended control, not a guarantee that an agent already has it.

Limits
